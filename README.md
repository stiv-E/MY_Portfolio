# Stivine Odhiambo — Portfolio

A static portfolio website built with HTML, CSS, and vanilla JavaScript. It has no build step or package dependencies.

## Preview locally

Open `portfolio/index.html` in a browser. The page loads its stylesheet and script from `portfolio/` and its images and fonts from `public/`.

## Project files

- `portfolio/index.html` — page content
- `portfolio/styles.css` — layout and styling
- `portfolio/script.js` — navigation, project filters, and reveal effects
- `public/assets/images/t001-nova/` — portfolio images
- `public/fonts/` — fonts used by the page
